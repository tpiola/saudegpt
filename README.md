# 🎓 SaúdeGPT — Formação para Atendentes de Farmácia

Plataforma EAD premium para formação de atendentes de farmácia.

## 🚀 Stack
- **Next.js 16** (Turbopack)
- **Tailwind CSS v4**
- **TypeScript**
- **Framer Motion**
- **DeepSeek V4 Flash** (chatbot IA)

## 📁 Estrutura
```
├── src/                    # Código-fonte
│   ├── app/                # Pages (Next.js App Router)
│   │   ├── api/            # API routes
│   │   ├── page.tsx        # Homepage
│   │   └── layout.tsx      # Root layout
│   ├── components/         # React components
│   ├── content/            # Currículo e conteúdo pedagógico
│   └── lib/                # Utilitários e hooks
├── infrastructure/         # Deploy, scripts, docs
│   ├── docs/               # Documentação
│   ├── scripts/            # Scripts auxiliares
│   └── config/             # ESLint, Prettier, PostCSS
├── public/                 # Assets estáticos
└── data/                   # Dados (cadastros, etc)
```
